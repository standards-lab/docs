# Architectures

An architecture defines a domain's compositional elements and the rules that bind them,
independent of any technology. A standard implements an architecture on a specific technology;
how each element is realized in a language or library emerges at its first consumer and is
documented in the repository that builds it. This index lists the blueprint's own
architectures, documented here in depth; implementations that live elsewhere are referenced
from the organization's catalog rather than documented here.

- [Elemental Architecture](elemental-architecture/index.md) — an organizational application
  architecture: the elements a program is built from and the rules that bind them.
